# HC Player — License references

This directory accompanies `LICENSE` and `THIRD-PARTY-NOTICES.md`.

Included here:

- `GPL-2.0.txt` — reference text for GPL-2.0 components that allow "or later".
- `LGPL-2.1.txt` — reference text for LGPL-2.1-or-later components such as libplacebo.
- `MediaInfo-BSD-2-Clause.txt` — notice required for the redistributed MediaInfo DLL.
- `WebView2-BSD-3-Clause.txt` — license shipped by Microsoft.Web.WebView2 1.0.3719.77.
- `Microsoft-WindowsAppSDK-2.4.0-NOTICE.txt` — redistribution notice and official license reference for the Windows App SDK bootstrap component.
- `mpv-FFmpeg-NOTICE.txt` — audited mpv/FFmpeg build identity and GPL notice.

The exact corresponding-source archive for each public HC Player binary release
must retain upstream copyright/license files for every library actually present
in the shipped multimedia build. `SOURCE-MANIFEST.md` records the frozen build
identity used by this release candidate.
