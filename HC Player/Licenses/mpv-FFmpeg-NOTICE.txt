HC Player multimedia stack — release notice

The HC Player 1.0 release candidate uses the following audited multimedia
binary:

  libmpv-2.dll SHA-256
  38acd030006062830d792a958c5f2adc293fa965996797980ec73d9610c309f4

The DLL identifies:

  mpv:    v0.41.0-85-g468d34c9b
  FFmpeg: N-122476-g685ceebd4

The mpv project is GPL-2.0-or-later by default. This build has the mpv "gpl"
feature enabled.

The FFmpeg build recipe used for this binary enables both --enable-gpl and
--enable-version3. The resulting FFmpeg combination is therefore distributed
under GPL version 3 or later. The build recipe audited for this DLL does not
use --enable-nonfree.

The combined libmpv binary also incorporates or links a number of third-party
libraries, including libplacebo, x264, x265, libass, libbluray, DVD libraries,
Rubber Band, OpenSSL and codec libraries. Their original copyright notices,
license files, source code, build recipes and patches must be preserved in the
corresponding-source archive for the exact HC Player release.
