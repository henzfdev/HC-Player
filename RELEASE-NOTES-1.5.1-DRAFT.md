# HC Player 1.5.1 — Release preparation

**Status: Store candidate, not yet compiled, signed or published.** This documentation covers the SEM TORRENT release branch only.

## Português (Brasil)

A versão 1.5.1 inclui uma correção de pontuação nas mensagens fixas do painel de comentários do YouTube em relação à versão 1.5.0. Os comentários reais recebidos do YouTube não são modificados.

O mecanismo de reprodução, SponsorBlock e integrações opcionais permanecem os mesmos. O AppId permanente do instalador Inno Setup também será preservado, permitindo upgrade sobre a versão anterior.

## English (United States)

Version 1.5.1 includes a punctuation correction in fixed YouTube comments panel messages compared with version 1.5.0. Actual comments retrieved from YouTube are not modified.

The playback engine, SponsorBlock and optional integrations remain unchanged. The permanent Inno Setup AppId will also be preserved to support upgrades from earlier versions.
